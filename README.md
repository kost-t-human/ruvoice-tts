# RuVoice TTS

Системный движок синтеза русской речи для Android на нейросети Silero `v5_5_ru`. Работает офлайн, ставится как обычный голос в настройках телефона, и любая читалка, умеющая Android TTS, читает им книги.

## Приватность

Всё офлайн. Разрешения на интернет в манифесте нет, ничего никуда не отправляется: модель и синтез целиком на телефоне. Экспорт и импорт настроек идут через системный выбор файла, права на хранилище для этого не нужны.

Разрешений в манифесте три, и все ради одного: чтобы чтение не тормозило при погасшем экране.

- `FOREGROUND_SERVICE` и `FOREGROUND_SERVICE_MEDIA_PLAYBACK`. Пока идёт чтение, движок работает как foreground-сервис с типом «воспроизведение медиа». Без этого при выключенном экране Android переводит процесс в ограниченную группу планировщика (sched group Restricted), синтез замедляется в разы, и между предложениями появляются паузы. По простою сервис из этого режима выходит.
- `POST_NOTIFICATIONS`. У foreground-сервиса обязательно есть уведомление: тихое, на канале минимальной важности, с текстом «Идёт чтение». Приложение это разрешение само не запрашивает. По документации Android, на Android 13+ без него уведомление не показывается в шторке, а сервис работает так же.

При выборе движка Android показывает предупреждение: «этот движок может собирать весь произносимый текст, включая пароли и номера карт». Это стандартная фраза для любого стороннего движка синтеза, система показывает её всем одинаково и от самого движка не зависит. У RuVoice возможности что-то собрать нет, см. выше.

## Зачем

Silero читает по-русски естественно и целиком работает на телефоне, без сети. Но сама по себе модель — это функция «строка → звук»: цифры, даты, сокращения и латиницу она не понимает, ударения в омографах ставит по своему разумению, пауз между абзацами не делает, темп не меняет.

RuVoice заворачивает модель в `TextToSpeechService` и добавляет всё, чего не хватает для чтения книг: нормализацию текста, ударения с пользовательским словарём, замены, паузы, отдельный голос для прямой речи и темп, который меняется после синтеза без искажения высоты. Читалке об этом знать не нужно — она видит обычный системный голос.

## Возможности

- **Пять голосов** модели `v5_5_ru`: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`. Частота 48 или 24 кГц.
- **Дополнительные голоса**: 29 русских голосов модели Silero `v5_cis_base_nostress` (лицензия MIT) отдельным паком, см. [Дополнительные голоса](#дополнительные-голоса).
- **Нормализация текста** — числа с падежами, даты, время, телефоны, годы, единицы, валюты, дроби, проценты, градусы, римские числа, сокращения, аббревиатуры по буквам, транслитерация латиницы, сноски `[1]`, переносы слов через дефис:

  | В тексте | Читается |
  |---|---|
  | `в 21:30` | в двадцать один час тридцать минут |
  | `+7 900 083-09-93` | плюс семь, девятьсот, ноль восемьдесят три, ноль девять, девяносто три |
  | `около 3 км` | около трёх километров |
  | `Николай II` | Николай второй |
  | `2 ч. л.` | две чайные ложки |
  | `5 тыс. руб.` | пять тысяч рублей |
  | `в 1917 году` | в тысяча девятьсот семнадцатом году |
  | `05.12.2020` | пятого декабря две тысячи двадцатого года |
  | `в 90-х` | в девяностых |
  | `около 500 рублей` | около пятисот рублей |
  | `с 500 рублями` | с пятьюстами рублями |
  | `2 книги` | две книги |
  | `3/4` | три четвёртых |
  | `−5 °C` | минус пять градусов цельсия |
  | `5 руб. 30 коп.` | пять рублей тридцать копеек |
  | `в XX веке` | в двадцатом веке |
  | `см. рис. 3` | смотри рисунок три |
  | `Агент ФСБ и порт USB` | агент эф эс бэ и порт ю эс би |
  | `iphone`, `sherlock` | айфон, шерлок |

- **Ударения**: [Silero Stress](https://github.com/snakers4/silero-stress) — словарь исключений, 37 тысяч фраз-подсказок и BERT-классификатор омографов (з`а`мок / зам`о`к по контексту), буква «ё» по словарю eyo там, где она бесспорна, поверх — ваш словарь для слов, где движок ошибается.
- **Замены** перед озвучиванием: алиасы, ударение с оглядкой на соседние слова, regex с `$1`, пропуск мусора `{skip}`, паузы `{pause:300}`, логическое ударение `*слово*`, темп и высота с точки в тексте `{prosody:150:110}`.
- **Прямая речь** (реплики с тире или кавычки в начале) — другим голосом, темпом и высотой. По умолчанию выключено, включается на вкладке «Голос».
- **Правила** — каждое правило нормализации, разбиения и ударений (римские цифры, даты, единицы, аббревиатуры по буквам, транслитерация, переносы, SSML, омографы, интонация…) можно выключить отдельно в меню ⋮ → «Настройки», там же длина куска для синтеза.
- **Ограничения** нормализации — что не читается и почему — собраны в [NORMALIZER.md](NORMALIZER.md). Обход почти всегда есть через словарь замен.
- **Паузы** после предложения, абзаца, запятой и на тире — задаются в миллисекундах. Паузы после запятой и на тире делает сама модель: знаку задаётся явная длительность, фраза не режется и звук не склеивается. Тире — «—», «–» и дефис или минус в пробелах; дефис внутри слова («кто-то») паузы не даёт.
- **Логическое ударение**: `*слово*` в тексте или замене (и `<emphasis>` в SSML) — модель выделяет слово интонацией; сила 1–3 и тумблер в меню ⋮ → «Настройки».
- **Подсветка читаемого слова**: движок сообщает читалке границы слов (`onRangeStart`), если она умеет их показывать.
- **Темп и высота**: читалка задаёт свои, движок умножает их на ваши коэффициенты. Темп меняется после синтеза через Sonic, без искажения высоты.
- **Проверка** прямо в приложении: кнопка «Прослушать» и «Разбор» — показывает, как текст разбился на сегменты, что именно уходит в модель после замен, нормализации и всех ударений (ударения над буквой) и где стоят паузы. То же окно открывается кнопкой «Проверить» на вкладках словарей.
- **Память**: модели выгружаются после N минут простоя и грузятся заново при следующем запросе; пока включён экранный чтец — не выгружаются (правило «Чтение с экрана»).
- **Экспорт и импорт** всех настроек вместе со словарями в один JSON-файл.
- **SSML**: `<break>`, `<prosody rate pitch>` (в том числе внутри предложения, не разрывая его; `pitch="robot"` — плоская высота), `<emphasis>`, `<p>`, `<s>`, если читалка такое присылает.
- **TalkBack и экранные чтецы.** Движок узнаёт, кто прислал текст (`SynthesisRequest.getCallerUid()`): TalkBack — из Google Play и открытая сборка, Samsung, Huawei, Jieshuo, Dianming или любое приложение с включённой службой доступности с речью. Для чтеца — свои настройки в разделе «Чтение с экрана» (меню ⋮ → «Настройки»), книги их не чувствуют:
  - служебные символы словами, как у самого TalkBack: `→` — «стрелка вправо», `×` — «знак умножения», `@` — «собака», `▾`, `⋮`, `✓`, и ещё сотни знаков по именам Unicode CLDR (`∑` — «сумма», `≈` — «приблизительно равно»);
  - без голоса прямой речи, без тишины перед фразой, без пауз между предложениями;
  - не выгружать модель, пока чтец включён (важнее выгрузки по простою; тот же переключатель — на вкладке «Паузы»);
  - свои темп, высота и громкость; темп TalkBack проходит до ×6 (книгам — до ×3, как раньше);
  - «Кто читает через движок» — последние отправители и кем они признаны, с ручной поправкой.

  Для TalkBack же: пунктуация в режиме «Все»/«Большинство» (TalkBack присылает названия знаков пометками `TtsSpan`, движок их читает), одиночная буква или знак по имени (`б` — «бэ», `#` — «решётка»), кэш коротких фраз — «кнопка», «включено», «дважды нажмите, чтобы активировать» второй раз звучат без счёта модели. Размеченное приложением (`TtsSpan`) читается как размечено: телефон из звонилки группами, время «семь часов пять минут», дата, деньги «сто рублей пятьдесят копеек», «по цифрам» и «по буквам». Подробно — [ACCESSIBILITY.md](ACCESSIBILITY.md).
- **Коды и номера карт по цифрам**: `Ваш код: 482913` — «четыре восемь два, девять один три», если рядом «код», «пароль», «PIN», «CVC»; карта `1234 5678 9012 3456` и `•• 1234` — группами по цифрам. Их набирают — «четыреста восемьдесят две тысячи…» пришлось бы переводить обратно.
- **Эмодзи словами** по именам Unicode CLDR, как у Android: `Привет 😀` — «Привет, широко улыбается», `🇷🇺` — «флаг: Россия»; тон кожи не читается, повтор подряд — один раз.
- **Доступный интерфейс**: одна строка — один переключатель для TalkBack, заголовки секций, ползунки с названием, действия TalkBack вместо свайпов в списках, «Прослушать» становится «Стоп», поиск по правилам с числом найденного вслух, чипы ударения различимы и на глаз (ударная буква заглавной и жирной), и на слух (номер слога), у каждого диалога заголовок, «Отменить» после удаления, «В словарь», очистки и импорта (при TalkBack — 30 с, чтобы дойти до кнопки). С физической клавиатурой и Switch Access: всё нажимаемое берёт фокус, Enter сохраняет, Ctrl+F — поиск. Проверки доступности Espresso — `AccessibilityChecksTest`, при шрифте 200 % и тёмной теме — `LargeTextTest`.

## Установка

Собранный APK лежит в [Releases](../../releases): скачать на телефон (arm64, Android 6.0+) и установить. Файл большой, около 230 МБ — внутри модели и два рантайма.

Две сборки в каждом релизе: `ruvoice-tts-X.Y.Z.apk` — с моделью внутри, работает сразу;
`ruvoice-tts-X.Y.Z-lite.apk` — без модели (~145 МБ вместо ~230), штатные голоса ставятся один раз паком
`ruvoice-pack-ru.zip` из релиза [«Паки голосов»](../../releases/tag/packs), дальше обновляется только
приложение. Сборки взаимозаменяемы: ставятся друг поверх друга, настройки и паки сохраняются.

Переход между сборками — обычная установка поверх, без удаления: настройки, словари и паки остаются.
С 0.12.1 или с полной сборки на lite: поставить lite, затем один раз поставить пак `ruvoice-pack-ru.zip`
(встроенной модели в lite нет, до установки пака голосов не будет — приложение само откроет диалог паков).
С lite на полную: поставить полную сборку, пак `ru` станет лишним, его можно удалить в «Дополнительных голосах».

Скорость на телефонах (RTF — время синтеза к длине звука, меньше лучше): Galaxy A32 (Helio G80, 2×A75 + 6×A55) 0,21, Redmi Note 13 5G (Dimensity 6080) и Xiaomi на Snapdragon 4 Gen 2 около 0,05. Вокодер, три четверти времени синтеза, работает в ExecuTorch (XNNPACK, fp32), остальное в TorchScript Lite: на 20 % быстрее и на столько же меньше процессорного времени, чем целиком в Lite, звук тот же. Память в работе 350–500 МБ.

## Сборка из исходников

Модели в репозитории не лежат (это сконвертированный пакет Silero, его проще собрать локально, чем хранить в git), поэтому перед сборкой их нужно получить. Нужны JDK 17, Android SDK 35, Python 3 с PyTorch.

```sh
# 1. Модель: официальный пакет v5_5_ru.pt (~145 МБ) кладём в tools/
pip install -r tools/requirements.txt
curl -L -o tools/v5_5_ru.pt https://models.silero.ai/models/tts/ru/v5_5_ru.pt

# 2. Конвертация в TorchScript Lite: tts_mel.ptl (текст → мел) и head.ptl (голова вокодера) —
#    модель, попадает в app/src/full/assets/silero/ (только сборка full); accentor.ptl, homo.ptl
#    и silero_ru.json — общие для full и lite, в app/src/main/assets/silero/.
#    Скрипт сам сверяет выход lite-модулей с оригиналом и печатает "verify: ok".
python3 tools/export_silero.py
# Пак дополнительных голосов собирается отдельно: ../venv-et/bin/python tools/export_pack.py cis_ru
# (или ru — штатный пак для сборки lite), см. «Дополнительные голоса»

# 2а. Ударения — из Silero Stress (MIT) вместо акцентора v5: перезаписывает accentor.ptl, homo.ptl,
#     стрессовую часть silero_ru.json и golden.json. Нужен venv с silero-stress.
pip install silero-stress
python3 tools/export_silero_stress.py
#     Заодно собирает системный словарь из tools/stress_fixes.txt и tools/phrases_extra.txt (tools/system_dicts.py).
#     В homo.ptl добавляется своя ветка для «все/всё» (tools/vse_top3.pt, дообучена на книгах с честной «ё»):
#     ошибок на ручной «ё» narusco вдвое меньше, остальные омографы решаются исходной моделью без изменений.

# 2б. Бэкбон вокодера (ConvNeXt, три четверти времени синтеза) — в ExecuTorch с XNNPACK: backbone.pte,
#     тоже в app/src/full/assets/silero/ (только full).
#     Только fp32: в fp16 XNNPACK на ARM копит ошибку, на golden-наборе SNR падает до 20 дБ.
#     Отдельный venv с executorch (pip install executorch torch --extra-index-url https://download.pytorch.org/whl/cpu).
#     Рантайм для Android: app/libs/executorch-1.5.0-xnnpack.aar собирает tools/build_executorch_aar.sh (NDK r28c);
#     готовый AAR с ossci-android.s3.amazonaws.com не годится — SIGILL на Cortex-A53/A73 (Snapdragon 680/685).
python3 tools/vocoder_et.py

# 2б. Таблица грамматических омографов (стен+ы / ст+ены по предлогу) — из морфословаря AOT (LGPL):
#     склонировать github.com/sokirko74/morph_dict, затем
python3 tools/aot_forms.py <morph_dict>/data/Russian
python3 tools/gram_table.py

# 2в. Таблица морфологии для нормализатора (род, число, падеж существительных и прилагательных) — из того же AOT:
python3 tools/aot_morph.py <morph_dict>/data/Russian
#     → app/src/main/assets/morph.bin, 13 МБ, 1,1 млн форм; ассет несжатый, читается через mmap, повторная сборка
#     даёт тот же файл. Что по нему решает нормализатор — в NORMALIZER.md.

# 3. Сборка и установка (flavor full — модель встроена в APK; для lite нужен ещё пак ruvoice-pack-ru.zip)
./gradlew :app:assembleFullDebug
adb install -r app/build/outputs/apk/full/debug/app-full-debug.apk
```

## Настройка

1. **Настройки Android → Система → Язык и ввод → Синтез речи** (на разных прошивках путь чуть отличается; при первом запуске приложение показывает справку «Как включить» с кнопкой прямо на этот экран, она же есть в меню) → предпочитаемый движок **RuVoice TTS**. Android спросит подтверждение с предупреждением про пароли и карты, см. «Приватность» выше. Читалки, которые выбирают движок сами, найдут его в своём списке под тем же именем.
2. Откройте приложение RuVoice. Вкладки:
   - **Голос** — голос, частота дискретизации, множители темпа и высоты (×0.5…×2 поверх того, что просит читалка), громкость голоса (×0.5…×2, громче — с мягким ограничением пиков), голос/темп/высота прямой речи, поле для проверки с кнопками «Прослушать» и «Разбор». Здесь же показаны системные темп и высота — те, что заданы в настройках Android и действуют для всех приложений, — и кнопка на системный экран синтеза речи, где они меняются.
   - **Паузы** — после предложения, абзаца, запятой и на тире в миллисекундах (ноль — только та пауза, что даёт сама модель), и через сколько минут простоя выгружать модели.
   - **Правила** — тумблеры правил нормализации, разбиения и ударений, сила логического ударения, длина куска.
   - **Ударения** — ваш словарь ударений, см. ниже.
   - **Замены** — ваш словарь замен, см. ниже.
   - **Проверка** — имена, которые стоит проверить на слух, копятся при чтении, если включить сборщик (по умолчанию выключен): слова с заглавной не в начале предложения, которых нет ни в словарях модели, ни в таблице морфологии, ни в списках пользователя. Ударение в незнакомом имени модель угадывает и ошибается примерно в каждом третьем, при этом «уверена» всегда (`tools/names_confidence.py`: 23 ошибки из 69, почти все с вероятностью 1,0) — поэтому списка «неуверенных» слов по вероятности модели больше нет. Тап по слову — в словарь ударений с выбором гласной и списка (при первом запуске создаётся пустой список «Имена», его можно удалить) или, переключателем в том же диалоге, в замены — когда имя надо ёфицировать («Курылев» → «Курылёв»); режим и списки назначения запоминаются. Свайп — скрыть: слово больше не собирается, найти и вернуть его можно по галочке «Скрытые». До двух тысяч записей, старые вытесняются. Кнопка с книгой рядом с корзиной собирает имена из файла книги (txt, fb2, epub, fb2.zip) сразу, без чтения вслух — те же правила отбора, книга в 1,3 МБ разбирается за секунды.
3. Меню в правом верхнем углу: **Экспорт настроек…** и **Импорт настроек…** (JSON с настройками, списками ударений и замен и списками вкладки «Проверка» вместе со скрытыми), **Дополнительные голоса…** (паки, см. ниже) и «О программе».

Кнопки «Сохранить» нет, всё сохраняется при уходе со вкладки.

## Словари

Словари — текстовые файлы в приватной папке приложения, редактируются через вкладки «Ударения» и «Замены», а целиком переносятся экспортом/импортом. Пустые строки и строки с `#` в начале пропускаются.

На каждой вкладке словарей может быть несколько **именных списков** — например, «Основной» и отдельный под серию книг. Сверху вкладки выбирается список, который редактируется, а при чтении действуют все включённые списки сразу (замены — общий порядок «длинные ключи раньше», при одинаковом ключе или слове побеждает более поздний список: системный идёт первым, остальные по алфавиту). Меню «⋮» рядом со списком: включить/выключить, новый, переименовать, удалить, импорт и экспорт. Поле «Поиск» по умолчанию ищет по всем спискам вкладки: строки чужих списков подписаны именем списка, тап открывает тот список и редактор строки; кнопка в поле меняет область — только этот список, свои, все или системный. Кнопка «Проверить» рядом со справкой открывает окно «Прослушать»/«Разбор», как на вкладке «Голос». Импорт принимает и файл в нашем формате, и словарь [Демагога](https://mytts.forum2x2.ru/t373-topic) (cp1251, `ключ=замена`, маска `*`) — кодировка определяется сама, список получает имя файла. «Экспорт для Демагога» пишет cp1251 и пропускает regex-правила, предлагая сохранить их отдельным файлом. Списки на десятки тысяч строк — нормально: правила индексируются по словам, на предложение пробуются только те, чьи слова в нём есть.

На обеих вкладках есть список **«Системный»** — встроенные поправки: 1,4 тысячи слов, где модель ставит ударение не так, как словари AOT и Викисловаря (или словарь Демагога с одним из них), 97 тысяч имён, фамилий, топонимов и терминов с ударением из первых абзацев русской Википедии, на которых модель ошибается (Бор+исович, +Оскар, В+ашингтон, Шевч+енко; в незнакомых именах она промахивается примерно в каждом третьем), и 6,5 тысяч фраз с омографами («амбарный замок = амбарный зам+ок», «все же = вс+ё же»), плюс несколько орфоэпических замен: «гм» → «гмм» (иначе модель проглатывает междометие), «дорого» → «дорога» (иначе окончание читается [ова], как у прилагательных). Его нельзя удалить и править, но можно выключить, как любой другой; при обновлении приложения он обновляется сам. Свои поправки к нему кладите в «Основной» — ваши списки действуют после системного.

### Ударения

Одна строка — одно слово: исходное написание, пробел, оно же со знаком `+` перед ударной гласной.

```
творог твор+ог
звонит звон+ит
```

Словарь применяется последним, после модели и омографов, регистр исходного слова сохраняется. В приложении ударение выбирается чипами по гласным, и слово можно сразу прослушать как читает модель и как будет с вашим ударением.

### Замены

Строка `ключ = замена`. Ключ из букв и цифр ищется как целое слово (или фраза), без учёта регистра; из нескольких подходящих правил побеждает более длинный ключ. `*` в ключе — маска: часть слова или целое слово (`прочита*`, `*ходить`, `нет * уже`); та же `*` в замене подставляет захваченное (`программ* = прогр+амм*`). Замена без `*` подменяет только буквы ключа, захваченное остаётся на своём месте (`туник* = тун+ик` читает «тун+ика», `ворот* города = вор+от г+орода` — «вор+отах г+орода») — как в словарях Говорилки и Демагога; пустая замена удаляет всё совпадение. Один ключ дважды — действует последняя строка. Ключ без букв (`***`) — обычный текст. Запятая в ключе совпадает и без пробела после неё, как в словарях Демагога. `$` в начале ключа — совпадение с учётом регистра (`$Ворон` — только имя), `$$` и `##` в начале — просто символы `$` и `#`; это тоже из Демагога. Ограничение: правило с маской ищется в окне вокруг своего якорного слова, поэтому если все `*` ключа вместе захватывают больше 64 символов, такое совпадение не найдётся — для реальных слов это недостижимо.

```
# алиас
Гарри = Г+арри

# ударение во фразе перебивает то, что выбрал бы движок для слова по отдельности
старый замок = старый з+амок

# «ё», которую в тексте не пишут
малек = малёк

# пропустить: пустая замена или {skip}
[1] =
Автор = {skip}

# regex: ключ с «~» в начале, в замене работают $1, $2; разделитель — « = » с пробелами,
# поэтому «=» внутри (?<=…) допустим. Регистр игнорируется, (?-i) в начале включает его
~(\d+)-(\d+) = $1 по $2
~(?<=\d)\s*% = процентов
~(?-i)\bБог\b = Б+ог

# пауза N миллисекунд (до 10000) там, где стоял ключ; между предложениями — тишина,
# внутри предложения — запятая такой длины, фраза синтезируется целиком
*** = {pause:800}

# логическое ударение на слове — модель выделит его интонацией
именно = *именно*

# темп и высота (проценты) с этого места до {prosody} или до конца абзаца; 0 в высоте — «робот»
(шёпотом) = {prosody:80:90}
```

Правило «малек = малёк» уже есть в списке «Замены» при первом запуске — как пример. Маркеры `{pause:N}`, `*слово*` и `{prosody:R:P}` можно писать и прямо в тексте, не только в замене. Маркеры снимаются до нормализации, а после ударений раскладываются по словам сопоставлением; слово, которое нормализация переписала (число, сокращение, латиница), получает пометку соседнего. В диалоге правила под полем «На что» свёрнут блок «Ударение»: чипы по гласным слова под курсором, тап ставит `+` перед гласной («замок = з+амок» без перепечатывания), и блок «Проверить»; есть справка по regex, ошибки паттерна и замены показываются сразу, а поле «Проверить на тексте» показывает результат применения правила. Битый regex в файле молча пропускается при чтении, остальные правила продолжают работать.

## Дополнительные голоса

Пак — zip-файл с моделью Silero и её голосами (около 80 МБ каждый), паки лежат в отдельном релизе [«Паки голосов»](../../releases/tag/packs) (тег `packs`, не привязан к версии приложения). Установка: меню → **Дополнительные голоса…** → **Установить из файла…** → выбрать скачанный zip. Интернет приложению по-прежнему не нужен, новых разрешений пак не требует. Голоса появляются в списке на вкладке «Голос» с пометкой пака: `ru_alexandr (cis_ru)`, и в списке голосов у читалок. Пак не входит в бэкап Android и в экспорт настроек — переносится только имя голоса, без пака оно сбрасывается на голос по умолчанию.

Какие паки есть:

- `ruvoice-pack-ru.zip` — штатная модель `v5_5_ru`, самая свежая, та же, что встроена в полную сборку
  (пять голосов, лицензия CC BY-NC-SA 4.0). Нужен только сборке lite.
- `ruvoice-pack-cis_ru.zip` — 29 русских голосов модели `v5_cis_base_nostress` (лицензия MIT). Добавлен
  как экспериментальный: модель старее, может хуже работать с ударениями, омографами и произношением, без интонации
  вопросов и восклицаний и без логического ударения.

Без единого голоса приложение сразу открывает диалог паков, а читалка по кнопке «установить данные»
попадает туда же.

В паке `cis_ru` 29 русских голосов: `ru_aigul, ru_albina, ru_alexandr, ru_alfia, ru_alfia2, ru_bogdan, ru_dmitriy, ru_eduard, ru_ekaterina, ru_gamat, ru_igor, ru_karina, ru_kejilgan, ru_kermen, ru_marat, ru_miyau, ru_nurgul, ru_oksana, ru_onaoy, ru_ramilia, ru_roman, ru_safarhuja, ru_saida, ru_sibday, ru_vika, ru_zara, ru_zhadyra, ru_zhazira, ru_zinaida`. Дикторы — из записей для татарского, калмыцкого, казахского и других языков, читающие по-русски; у части голосов слышен акцент. Лицензия модели MIT, для голосов пака некоммерческое ограничение `v5_5_ru` не действует.

Ударения, словари, замены, прямая речь, паузы, темп и высота работают как со штатными голосами — весь конвейер тот же, другая только модель синтеза. Чего у неё нет: интонации вопросов и восклицаний (типы предложений) и логического ударения (`*слово*`); восклицательный знак и апостроф до модели не доходят (так устроена таблица символов этой модели). Голос прямой речи выбирается из того же движка, что основной: в памяти держится одна модель.

Собрать пак самому: скачать модель в `tools/` (`https://models.silero.ai/models/tts/ru/v5_cis_base_nostress.pt` для `cis_ru`, `https://models.silero.ai/models/tts/ru/v5_5_ru.pt` как `tools/v5_5_ru.pt` для `ru`) и запустить `../venv-et/bin/python tools/export_pack.py cis_ru` (или `ru` для штатной модели), результат в `dist/`. Пак привязан к формату приложения (`format: 2` в `pack.json`): после смены рантайма синтеза старый пак попросит пересборки.

## Как это работает

Текст запроса режется на абзацы, к каждому применяются замены, потом абзац режется на предложения (инициалы и сокращения вроде «стр.» предложение не заканчивают, предложения длиннее 400 символов дополнительно делятся по запятым). Каждое предложение проходит нормализацию: пунктуация → числа, даты, единицы, сокращения → аббревиатуры по буквам → латиница в кириллицу → фильтр по алфавиту модели (скобки становятся запятыми — пауза на вставке, правило «Пауза на скобках»). Дальше ударения в четыре прохода: грамматика (слово из таблицы падежных омографов получает ударение по предлогу, числительному или местоимению перед ним: «вдоль стен+ы», «в ст+ены», «за сел+о», «я нош+у»; по таблице морфологии — и по прилагательному, если оно согласуется со словом только в одном числе: «высокие ст+ены», «высокой стен+ы», «эти р+уки», через слово или предложную группу — только во мн.: «покрытые пылью д+оски», «почерневшие от времени д+оски»; «все» перед словом, которое бывает только во мн. ч., читается «вс+е»: «все окна», «все крупные»), омографы (сначала фразы-подсказки, при промахе — BERT по окну в 300 символов; фразы системного словаря собраны из чужих словарей замен, из контекстов ё-омографов Википедии — все/всё, озера/озёра, сестры/сёстры: `tools/yo_contexts.py`, контекст встречается в дампе от 20 раз с одним вариантом в 95 % — и вручную по частым промахам HomographResolutionEval; замены применяются до ударений, поэтому такая фраза перебивает и грамматику, и BERT), буква «ё» по словарю eyo там, где она бесспорна (ёжик, зелёный; правило «Буква „ё“ по словарю»), акцентор со словарём исключений, ваш словарь, и уже после всех ударений — твёрдое [э] в заимствованиях (энергия, тест, компьютер, проект: около тысячи слов с производными из приложения Викисловаря по орфоэпическому словарю, `assets/hard_e.txt`; правило «Твёрдое [э] в заимствованиях». Замена идёт последней нарочно: на «энэргия» акцентор промахивается, а «интэрнэт» оставляет без ударения; слова с равноправными вариантами (диарея, аксессуар) остаются за моделью). Полученную строку с `+` получает модель Silero вместе с голосом, типом предложения (повествование, восклицание и четыре вида вопроса — интонация от этого зависит), посимвольными коэффициентами темпа и высоты, маской логического ударения и явной длительностью запятых и тире (паузы «после запятой» и «на тире»). По длительностям символов из ответа модели читалке сообщаются границы слов, края звука сглаживаются, темп меняется через Sonic, и в конце добавляется тишина после предложения или абзаца.

Модели грузятся один раз при старте сервиса в фоновом потоке и выгружаются по таймеру простоя; выгрузка и синтез синхронизированы, так что модуль не исчезнет посреди запроса.

Инструментальные тесты сверяют выход конвертированных моделей с эталоном `golden.json` (он снят с оригинальной модели тем же `tools/export_silero.py`), гоняют сервис через платформенный `TextToSpeech`, как это делает читалка, и считают точность омографов на настоящих предложениях (`HomographEvalTest`, набор [HomographResolutionEval](https://huggingface.co/datasets/inkoziev/HomographResolutionEval) Ильи Козиева, CC BY 4.0, 1741 предложение; копия в `app/src/test/resources/homograph_eval/`): сейчас 85 %, трещотка на 84 %. Тот же набор без телефона — `tools/homo_eval.py`. Букву «ё» проверяет `YoEvalTest`: 2000 предложений русской Википедии с «ё» (`app/src/test/resources/yo_eval/`, выборка `tools/wiki_yo_corpus.py` из дампа), «ё» стирается и ставится заново: восстанавливается 96 %, трещотка на 92 %; полный корпус в 30 тысяч предложений гоняет `tools/yo_eval.py` (однозначные слова по словарю eyo — 100 % (словарь ставит их до модели; ещё в 506 местах он дописывает «ё», которой нет в самой Википедии: остаётся, идёт, счёт), омографы вроде все/всё — 90 %, лишних «ё» в омографах 179 на 30 тысяч предложений). `GramPassCorpusTest` проверяет грамматический проход на фразах чужих словарей (локальный `local/ss_rows.tsv`, без него пропускается): правило не должно спорить со словарём чаще, чем в 2,5 % сработок (сейчас 10 тысяч сработок, споров 1,2 %).

tools/yo_contexts.py                       контексты ё-омографов из дампа Википедии → app/build/yo_phrases.txt (группа в phrases_extra.txt)
tools/wiki_names.py                        имена с ударением из первых абзацев Википедии, где модель ставит иначе → tools/wiki_names.txt (в системный словарь)
tools/names_confidence.py                   уверенность акцентора на именах: 23 ошибки из 69 при вероятности ≈ 1,0, порог бесполезен
tools/nicolai_to_plus.py                  словарь под Николая («<» после гласной) → наш формат

## Лицензии и благодарности

- **[Silero Stress](https://github.com/snakers4/silero-stress)** (MIT) — акцентор, словарь исключений, фразы и BERT-классификатор омографов (`accentor.ptl`, `homo.ptl`, стрессовая часть `silero_ru.json`). - **[AOT — морфологический словарь](https://github.com/sokirko74/morph_dict)** (LGPL, по грамматическому словарю Зализняка) — источник таблицы падежных омографов (`gram` в `silero_ru.json`, около тысячи форм), таблицы морфологии нормализатора (`assets/morph.bin`, 1,1 млн форм существительных и прилагательных — род, число, падеж) и арбитр при отборе поправок ударений `tools/stress_fixes.txt` (1,4 тысячи слов). Второй арбитр — русские статьи английского [Викисловаря](https://en.wiktionary.org) в выгрузке [kaikki.org](https://kaikki.org/dictionary/Russian/) (CC BY-SA); частотность форм — [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (CC BY-SA). Поправка попадает в список, только если оба словаря согласны между собой и расходятся с моделью, либо со словарём Демагога согласен хотя бы один из них (эти просмотрены руками).
- **[Викисловарь](https://ru.wiktionary.org)**, русский и [английский](https://en.wiktionary.org) (CC BY-SA), выгрузки kaikki.org — ударения в устойчивых выражениях и многословных терминах для фраз системного словаря (`tools/phrases_extra.txt`): в русском ударение восстановлено из транскрипции IPA, в английском взято из заголовка статьи; в аппку попали только те ~800 фраз, где модель ставит иначе, просмотрены руками.
- **[«Грамматический словарь русского языка» А. А. Зализняка](https://github.com/gramdict/zalizniak-2010)**, 6-е издание (данные опубликованы правообладателем под **CC BY-NC**) — пометы об ударении в идиомах: ударение на предлоге и частице («с бо́ку на́ бок», «не́ был», «бе́з толку»; `tools/phrases_clitic.txt`, предлог слеплен со словом в одно, иначе модель читает оба ударными) и три десятка фраз с особой формой слова («два шага́», «во хмелю́»; в `tools/phrases_extra.txt`).
