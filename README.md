# RuVoice TTS

Системный движок синтеза русской речи для Android на нейросети Silero `v5_5_ru`. Работает офлайн, ставится как обычный голос в настройках телефона, и любая читалка, умеющая Android TTS, читает им книги.

## Приватность

Всё офлайн. У приложения нет ни одного разрешения (в манифесте пусто), интернет ему не нужен, ничего никуда не отправляется: модель и синтез целиком на телефоне. Экспорт и импорт настроек идут через системный выбор файла, права на хранилище для этого не нужны.

При выборе движка Android показывает предупреждение: «этот движок может собирать весь произносимый текст, включая пароли и номера карт». Это стандартная фраза для любого стороннего движка синтеза, система показывает её всем одинаково и от самого движка не зависит. У RuVoice возможности что-то собрать нет, см. выше.

## Зачем

Silero читает по-русски естественно и целиком работает на телефоне, без сети. Но сама по себе модель — это функция «строка → звук»: цифры, даты, сокращения и латиницу она не понимает, ударения в омографах ставит по своему разумению, пауз между абзацами не делает, темп не меняет.

RuVoice заворачивает модель в `TextToSpeechService` и добавляет всё, чего не хватает для чтения книг: нормализацию текста, ударения с пользовательским словарём, замены, паузы, отдельный голос для прямой речи и темп, который меняется после синтеза без искажения высоты. Читалке об этом знать не нужно — она видит обычный системный голос.

## Возможности

- **Пять голосов** модели `v5_5_ru`: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`. Частота 48 или 24 кГц.
- **Нормализация текста** — числа с падежами, даты, время, годы, единицы, валюты, дроби, проценты, градусы, римские числа, сокращения, аббревиатуры по буквам, транслитерация латиницы, сноски `[1]`, переносы слов через дефис:

  | В тексте | Читается |
  |---|---|
  | `в 21:30` | в двадцать один час тридцать минут |
  | `около 3 км` | около трёх километров |
  | `Николай II` | Николай второй |
  | `2 ч. л.` | две чайные ложки |
  | `5 тыс. руб.` | пять тысяч рублей |
  | `в 1917 году` | в тысяча девятьсот семнадцатом году |
  | `05.12.2020` | пятого декабря две тысячи двадцатого года |
  | `в 90-х` | в девяностых |
  | `около 500 рублей` | около пятисот рублей |
  | `с 500 рублями` | с пятьюстами рублями |
  | `2 книги` | две книги |
  | `3/4` | три четвёртых |
  | `−5 °C` | минус пять градусов цельсия |
  | `5 руб. 30 коп.` | пять рублей тридцать копеек |
  | `в XX веке` | в двадцатом веке |
  | `см. рис. 3` | смотри рисунок три |
  | `Агент ФСБ и порт USB` | агент эф эс бэ и порт ю эс би |
  | `iphone`, `sherlock` | айфон, шерлок |

- **Ударения**: [Silero Stress](https://github.com/snakers4/silero-stress) — словарь исключений, 37 тысяч фраз-подсказок и BERT-классификатор омографов (з`а`мок / зам`о`к по контексту), поверх — ваш словарь для слов, где движок ошибается.
- **Замены** перед озвучиванием: алиасы, ударение с оглядкой на соседние слова, regex с `$1`, пропуск мусора `{skip}`, паузы `{pause:300}`, логическое ударение `*слово*`, темп и высота с точки в тексте `{prosody:150:110}`.
- **Прямая речь** (реплики с тире или кавычки в начале) — другим голосом, темпом и высотой. По умолчанию выключено, включается на вкладке «Голос».
- **Правила** — каждое правило нормализации, разбиения и ударений (римские цифры, даты, единицы, аббревиатуры по буквам, транслитерация, переносы, SSML, омографы, интонация…) можно выключить отдельно на вкладке «Правила», там же длина куска для синтеза.
- **Ограничения** нормализации — что не читается и почему — собраны в [NORMALIZER.md](NORMALIZER.md). Обход почти всегда есть через словарь замен.
- **Паузы** после предложения, абзаца и запятой — задаются в миллисекундах. Паузу после запятой делает сама модель: запятой задаётся явная длительность, фраза не режется и звук не склеивается.
- **Логическое ударение**: `*слово*` в тексте или замене (и `<emphasis>` в SSML) — модель выделяет слово интонацией; сила 1–3 и тумблер на вкладке «Правила».
- **Подсветка читаемого слова**: движок сообщает читалке границы слов (`onRangeStart`), если она умеет их показывать.
- **Темп и высота**: читалка задаёт свои, движок умножает их на ваши коэффициенты. Темп меняется после синтеза через Sonic, без искажения высоты.
- **Проверка** прямо в приложении: кнопка «Прослушать» и «Разбор» — показывает, как текст разбился на сегменты, во что превратилась каждая фраза и где стоят паузы.
- **Память**: модели выгружаются после N минут простоя и грузятся заново при следующем запросе.
- **Экспорт и импорт** всех настроек вместе со словарями в один JSON-файл.
- **SSML**: `<break>`, `<prosody rate pitch>` (в том числе внутри предложения, не разрывая его; `pitch="robot"` — плоская высота), `<emphasis>`, `<p>`, `<s>`, если читалка такое присылает.

## Установка

Собранный APK лежит в [Releases](../../releases): скачать на телефон (arm64, Android 8.0+) и установить. Файл большой, около 200 МБ — внутри три модели.

## Сборка из исходников

Модели в репозитории не лежат (это сконвертированный пакет Silero, его проще собрать локально, чем хранить в git), поэтому перед сборкой их нужно получить. Нужны JDK 17, Android SDK 35, Python 3 с PyTorch.

```sh
# 1. Модель: официальный пакет v5_5_ru.pt (~145 МБ) кладём в tools/
pip install -r tools/requirements.txt
curl -L -o tools/v5_5_ru.pt https://models.silero.ai/models/tts/ru/v5_5_ru.pt

# 2. Конвертация в TorchScript Lite: tts.ptl, accentor.ptl, homo.ptl и silero_ru.json
#    появятся в app/src/main/assets/silero/. Скрипт сам сверяет выход lite-модулей
#    с оригиналом и печатает "verify: ok".
python3 tools/export_silero.py

# 2а. Ударения — из Silero Stress (MIT) вместо акцентора v5: перезаписывает accentor.ptl, homo.ptl,
#     стрессовую часть silero_ru.json и golden.json. Нужен venv с silero-stress.
pip install silero-stress
python3 tools/export_silero_stress.py
#     Заодно накладывает tools/stress_fixes.txt (поправки ударений) и tools/phrases_extra.txt (наши фразы-подсказки).

# 2б. Таблица грамматических омографов (стен+ы / ст+ены по предлогу) — из морфословаря AOT (LGPL):
#     склонировать github.com/sokirko74/morph_dict, затем
python3 tools/aot_forms.py <morph_dict>/data/Russian
python3 tools/gram_table.py

# 3. Сборка и установка
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Настройка

1. **Настройки Android → Система → Язык и ввод → Синтез речи** (на разных прошивках путь чуть отличается; при первом запуске приложение показывает справку «Как включить» с кнопкой прямо на этот экран, она же есть в меню) → предпочитаемый движок **RuVoice TTS**. Android спросит подтверждение с предупреждением про пароли и карты, см. «Приватность» выше. Читалки, которые выбирают движок сами, найдут его в своём списке под тем же именем.
2. Откройте приложение RuVoice. Вкладки:
   - **Голос** — голос, частота дискретизации, множители темпа и высоты (×0.5…×2 поверх того, что просит читалка), голос/темп/высота прямой речи, поле для проверки с кнопками «Прослушать» и «Разбор». Здесь же показаны системные темп и высота — те, что заданы в настройках Android и действуют для всех приложений, — и кнопка на системный экран синтеза речи, где они меняются.
   - **Паузы** — после предложения, абзаца и запятой в миллисекундах (ноль — только та пауза, что даёт сама модель), и через сколько минут простоя выгружать модели.
   - **Правила** — тумблеры правил нормализации, разбиения и ударений, сила логического ударения, длина куска.
   - **Ударения** — ваш словарь ударений, см. ниже.
   - **Замены** — ваш словарь замен, см. ниже.
3. Меню в правом верхнем углу: **Экспорт настроек…** и **Импорт настроек…** (JSON с настройками, словарём ударений и заменами) и «О программе».

Кнопки «Сохранить» нет, всё сохраняется при уходе со вкладки.

## Словари

Словари — текстовые файлы в приватной папке приложения, редактируются через вкладки «Ударения» и «Замены», а целиком переносятся экспортом/импортом. Пустые строки и строки с `#` в начале пропускаются.

На каждой вкладке словарей может быть несколько **именных списков** — например, «Основной» и отдельный под серию книг. Сверху вкладки выбирается список, который редактируется, а при чтении действуют все включённые списки сразу (замены — общий порядок «длинные ключи раньше», у ударений при совпадении слова побеждает список, чьё имя позже по алфавиту). Меню «⋮» рядом со списком: включить/выключить, новый, переименовать, удалить, импорт и экспорт. Импорт принимает и файл в нашем формате, и словарь [Демагога](https://mytts.forum2x2.ru/t373-topic) (cp1251, `ключ=замена`, маска `*`) — кодировка определяется сама, список получает имя файла. «Экспорт для Демагога» пишет cp1251 и пропускает regex-правила, предлагая сохранить их отдельным файлом. Списки на десятки тысяч строк — нормально: правила индексируются по словам, на предложение пробуются только те, чьи слова в нём есть.

### Ударения

Одна строка — одно слово: исходное написание, пробел, оно же со знаком `+` перед ударной гласной.

```
творог твор+ог
звонит звон+ит
```

Словарь применяется последним, после модели и омографов, регистр исходного слова сохраняется. В приложении ударение выбирается чипами по гласным, и слово можно сразу прослушать как читает модель и как будет с вашим ударением.

### Замены

Строка `ключ = замена`. Ключ из букв и цифр ищется как целое слово (или фраза), без учёта регистра; из нескольких подходящих правил побеждает более длинный ключ. `*` в ключе — маска: часть слова или целое слово (`прочита*`, `*ходить`, `нет * уже`); та же `*` в замене подставляет захваченное (`программ* = прогр+амм*`). Замена без `*` подменяет только буквы ключа, захваченное остаётся на своём месте (`туник* = тун+ик` читает «тун+ика», `ворот* города = вор+от г+орода` — «вор+отах г+орода») — как в словарях Говорилки и Демагога; пустая замена удаляет всё совпадение. Один ключ дважды — действует последняя строка. Ключ без букв (`***`) — обычный текст. Запятая в ключе совпадает и без пробела после неё, как в словарях Демагога. `$` в начале ключа — совпадение с учётом регистра (`$Ворон` — только имя), `$$` и `##` в начале — просто символы `$` и `#`; это тоже из Демагога. Ограничение: правило с маской ищется в окне вокруг своего якорного слова, поэтому если все `*` ключа вместе захватывают больше 64 символов, такое совпадение не найдётся — для реальных слов это недостижимо.

```
# алиас
Гарри = Г+арри

# ударение во фразе перебивает то, что выбрал бы движок для слова по отдельности
старый замок = старый з+амок

# «ё», которую в тексте не пишут
малек = малёк

# пропустить: пустая замена или {skip}
[1] =
Автор = {skip}

# regex: ключ с «~» в начале, в замене работают $1, $2; разделитель — « = » с пробелами,
# поэтому «=» внутри (?<=…) допустим. Регистр игнорируется, (?-i) в начале включает его
~(\d+)-(\d+) = $1 по $2
~(?<=\d)\s*% = процентов
~(?-i)\bБог\b = Б+ог

# пауза N миллисекунд (до 10000) там, где стоял ключ; между предложениями — тишина,
# внутри предложения — запятая такой длины, фраза синтезируется целиком
*** = {pause:800}

# логическое ударение на слове — модель выделит его интонацией
именно = *именно*

# темп и высота (проценты) с этого места до {prosody} или до конца абзаца; 0 в высоте — «робот»
(шёпотом) = {prosody:80:90}
```

Правила «старый замок = старый з+амок» и «малек = малёк» уже есть в списке «Замены» при первом запуске — как примеры. Маркеры `{pause:N}`, `*слово*` и `{prosody:R:P}` можно писать и прямо в тексте, не только в замене. Маркеры снимаются до нормализации, а после ударений раскладываются по словам сопоставлением; слово, которое нормализация переписала (число, сокращение, латиница), получает пометку соседнего. В диалоге правила есть справка по regex, ошибки паттерна и замены показываются сразу, а поле «Проверить на тексте» показывает результат применения правила. Битый regex в файле молча пропускается при чтении, остальные правила продолжают работать.

## Как это работает

Текст запроса режется на абзацы, к каждому применяются замены, потом абзац режется на предложения (инициалы и сокращения вроде «стр.» предложение не заканчивают, предложения длиннее 400 символов дополнительно делятся по запятым). Каждое предложение проходит нормализацию: пунктуация → числа, даты, единицы, сокращения → аббревиатуры по буквам → латиница в кириллицу → фильтр по алфавиту модели. Дальше ударения в четыре прохода: грамматика (слово из таблицы падежных омографов получает ударение по предлогу, числительному или местоимению перед ним: «вдоль стен+ы», «в ст+ены», «за сел+о», «я нош+у»), омографы (сначала фразы-подсказки, при промахе — BERT по окну в 300 символов), акцентор со словарём исключений, ваш словарь. Полученную строку с `+` получает модель Silero вместе с голосом, типом предложения (повествование, восклицание и четыре вида вопроса — интонация от этого зависит), посимвольными коэффициентами темпа и высоты, маской логического ударения и явной длительностью запятых (пауза после запятой). По длительностям символов из ответа модели читалке сообщаются границы слов, края звука сглаживаются, темп меняется через Sonic, и в конце добавляется тишина после предложения или абзаца.

Модели грузятся один раз при старте сервиса в фоновом потоке и выгружаются по таймеру простоя; выгрузка и синтез синхронизированы, так что модуль не исчезнет посреди запроса.

## Разработка

```sh
./gradlew :app:testDebugUnitTest          # JVM-тесты: нормализация, ударения, замены, паузы, SSML
./gradlew :app:connectedDebugAndroidTest  # на устройстве: модели против эталона, сервис через TextToSpeech API
```

Инструментальные тесты сверяют выход конвертированных моделей с эталоном `golden.json` (он снят с оригинальной модели тем же `tools/export_silero.py`) и гоняют сервис через платформенный `TextToSpeech`, как это делает читалка.

```

  SileroModels.kt       загрузка .ptl, вызовы accentor/homo/tts
  SileroData.kt         словари и алфавит модели из silero_ru.json
  Prefs.kt              настройки, файлы словарей, экспорт/импорт
  SettingsActivity.kt, SettingsPages.kt, DictFragments.kt   UI
  text/                 Normalizer, Abbrev, Stress, BertTokenizer, Replacements, Splitter, SentenceType, Ssml
  audio/                Pcm (float → int16 с насыщением), Tempo (Sonic), Pauses
app/src/main/java/sonic/Sonic.java        растяжение темпа
app/src/main/assets/silero/               модели и silero_ru.json
tools/export_silero.py                    конвертация v5_5_ru.pt
tools/export_silero_stress.py             ударения из Silero Stress поверх (accentor.ptl, homo.ptl)
tools/stress_survey.py, stress_compare.py сверка ударений модели со словарями замен (см. комментарии)
tools/aot_forms.py, wikt_forms.py          словоформы с ударениями из AOT и Викисловаря → app/build/*.tsv
tools/aot_survey.py                        Silero Stress по всем однозначным формам AOT: промахи модели
tools/gram_table.py                        таблица падежных омографов из AOT → «gram» в silero_ru.json
tools/stress_fixes.py, phrases_extra.py    поправки ударений и фразы-подсказки поверх пакета (см. комментарии)
tools/nicolai_to_plus.py                  словарь под Николая («<» после гласной) → наш формат
```

- **[Silero Stress](https://github.com/snakers4/silero-stress)** (MIT) — акцентор, словарь исключений, фразы и BERT-классификатор омографов (`accentor.ptl`, `homo.ptl`, стрессовая часть `silero_ru.json`). На словарях замен из живых книг совпадает с ними в 87 % ударений против 81 % у акцентора из `v5_5_ru`.
- **[AOT — морфологический словарь](https://github.com/sokirko74/morph_dict)** (LGPL, по грамматическому словарю Зализняка) — источник таблицы падежных омографов (`gram` в `silero_ru.json`, около тысячи форм) и арбитр при отборе поправок ударений `tools/stress_fixes.txt`. Второй арбитр — русские статьи английского [Викисловаря](https://en.wiktionary.org) в выгрузке [kaikki.org](https://kaikki.org/dictionary/Russian/) (CC BY-SA), в аппку из него ничего не попадает; частотность форм — [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (CC BY-SA). Поправка попадает в список, только если оба словаря согласны между собой и расходятся с моделью.
- **[Sonic](https://github.com/waywardgeek/sonic)** (Bill Cox) — растяжение темпа без изменения высоты, Apache-2.0. Java-порт лежит в `app/src/main/java/sonic/Sonic.java`.
- **PyTorch Android Lite** — рантайм для TorchScript-моделей на устройстве.
- **[ru-normalizr](https://github.com/NickZaitsev/ru-normalizr)** (Nick Zaitsev, MIT) — корпус из 563 пар «вход → выход» для тестов нормализатора (`app/src/test/resources/ru_normalizr.json`) и несколько идей оттуда: чтение ссылок по частям, буква после цифры названием, согласование числа с родом существительного. Код не заимствован.
- **[OpenCorpora](http://opencorpora.org/)** (CC BY-SA 4.0) — из его словаря через `pymorphy3-dicts-ru` выжаты списки исключений для рода существительных на «-ь» (`text/SoftSignGender.kt`).
