# Нормализация текста: известные ограничения

Нормализатор работает регулярными выражениями и небольшими списками слов; морфология — только там, где без неё никак: таблица AOT «форма → часть речи, род, число, падеж» для существительных и прилагательных (`assets/morph.bin`, 13 МБ, mmap без разбора при старте, `text/Morph.kt`, строит `tools/aot_morph.py`). Таблица подключается в трёх местах ниже; без неё (в тестах) те же правила работают по окончаниям и спискам. Всё, что можно вывести из окончания соседнего слова, предлога или короткого списка, нормализатор делает; ниже — то, чего он не делает, и почему. Для каждого случая есть обход через словарь замен на вкладке «Замены».

## Сокращения-прилагательные

`гос.`, `офиц.`, `полит.`, `междунар.`, `лат.`, `греч.`, `физ.`, `хим.`, `мат.`, `ист.`, `экон.`, `соц.`, `фед.`, `муниц.`, `тех.`, `мед.`, `юр.`, `воен.`, `англ.`, `нем.`, `фр.`, `рус.`, `рос.`, `науч.`, `лит.` (список `adjAbbrevStems` в `Normalizer.kt`) раскрываются по таблице морфологии: существительное следом — через одно-два прилагательных («гос. часовой службы») — должно быть в таблице, и все его разборы (с учётом прилагательных между) должны давать одну форму: `снижение гос. контроля` → «государственного», `в гос. органах` → «государственных», `тех. задание` → «техническое», `офиц. часовой стрелки` → «официальной».

У слова «службы» два разбора — родительный единственного и именительный/винительный множественного («государственной» / «государственные»). Тогда решает слово перед сокращением: существительное (`порядок гос. службы` → «государственной») или, через «и/или», существительное только в родительном (`контроля и полит. системы` → «политической»). В остальных случаях («проверил гос. службы», «все гос. службы», «мед. помощь» — именительный или винительный) сокращение остаётся как есть: раскрыть в неверную форму хуже.

Без таблицы работают только однозначные случаи: `от лат. homo` → «от латинского», `с греч.` → «с греческого», `Св. Георгия` → «Святого Георгия», `Св. Анны` → «Святой Анны» (род имени — по списку женских имён, для незнакомого имени берётся мужской).

Обход: замена `гос. = государственной` для конкретного текста.

## Падеж числительного

Падеж берётся из предлога («около 500 рублей» → «пятисот»), из списка глаголов и существительных с известным управлением («достигаем 5 целей», «требует 5 минут», «не хватает 3 рублей», «потеря 100 долларов») и из слова следом по таблице морфологии: если все его разборы дают одну форму числительного, берётся она («5 путями» → «пятью», «7 гномам» → «семи», «1 другу» → «одному», «в 1 доме» → «одном», «1 двери» → «одной»). Родительный после числа — обычная конструкция «пять минут», «два стола», числительное остаётся в именительном; при 2–4 родительный множественного («3 друзей», «3 рабочих дня») тоже не трогаем — он омонимичен прилагательному. Слова не из таблицы решают окончания («с 5 друзьями» → «пятью», «в 5 случаях» → «пяти»). Всё остальное читается в именительном.

Прилагательное или причастие перед числом тоже задаёт падеж, если оно есть в таблице: его падежи во множественном числе пересекаются с падежами существительного после числа, и если остаётся одна клетка не именительного и не винительного — число склоняется: «последних 20-30 лет» → «двадцати-тридцати», «первых 5 минут» → «пяти», «в последних 5 случаях» → «пяти». «Последние 5 лет» — именительный/винительный, как раньше; при одушевлённом существительном «-их/-ых» может быть винительным («последних 5 друзей»), поэтому оставляется. Причастий в таблице нет.

Падеж не переносится через союз: «при −20 °C и −1 %» → «при минус двадцати градусах Цельсия и минус один процент». Первое число склоняется по предлогу, второе уже не видит его.

## Род существительного

Для «1» и «2» род берётся из таблицы морфологии по слову следом: `1 ночь` → «одна», `1 конь` → «один», `1 такси` → «одно», `1 имя` → «одно», `2 двери` → «две», `1 книгу` → «одну», `1 коня` → «одного». Слово общего рода («сирота», «коллега»), незнакомое таблице или из стоп-списка («евро» в AOT среднего рода, «1 года») уходит в старые правила по окончанию: `1 женщина` → «одна», `1 сообщение` → «одно», `2 книги` → «две»; существительные на «-ь» в 93 % случаев решаются суффиксом (-ость, -знь, шипящая, -вь, -сть — женские; -ль, -нь, -рь — мужские), остальное — списками исключений на четыре сотни слов (`text/SoftSignGender.kt`), слово на «-ль/-нь/-рь», которого в списке нет, считается мужским. Известное таблице слово мужского рода правила по окончанию не трогают («2 столы» → «два», не «две»).

Порядковые с суффиксом «-й» и «-е» тоже смотрят на слово следом, сначала по таблице (род и число существительного), потом по окончанию: `в 3-й дивизии` → «третьей», `1-й номер` → «первый», `2-е ножницы` → «вторые», `2-е место` → «второе». Женское имя перед числом — по списку имён: `Елизаветы 3-й` → «третьей».

## Двусмысленности, решённые в пользу частого

- Дефис между числами — диапазон, не вычитание: `10-20` → «десять-двадцать», даже после «x =». Вычитание пишется с пробелами или знаком минус: `10 − 20`.
- `6м номере` → «шесть метров номере». Голое «м» после цифры — метры; порядковое пишется через дефис (`6-м`) или полностью.
- `XIX в у нас` — «в» без точки после римского числа остаётся предлогом. Век — с точкой: `XIX в.`.
- `5 М`, `5 мкМ` — оставляются как есть (молярность), строчные `5 м`, `5 мкм` — метры и микрометры.
- `С. 6` — не «страница шесть»: слишком похоже на инициал. Страница — `стр. 6`.
- `200-300 г` без точки — граммы; `В 300-200 г.` с точкой и без продукта рядом — годы.
- `10:07` → «десять часов семь минут», а не «десять ноль семь». На слух первое понятнее.
- Диапазоны лет читаются через тире: `1941–1945 гг.` → «тысяча девятьсот сорок первый – тысяча девятьсот сорок пятый годы», без перестройки в «с … по …».

## Телефоны

Номер читается группами через запятую (пауза) с ведущими нулями: `+7 012 345-06-78` → «плюс семь, ноль двенадцать, триста сорок пять, ноль шесть, семьдесят восемь». Группы берутся как написаны; группа длиннее трёх цифр режется парами (`0678` → «ноль шесть, семьдесят восемь»), номер вплотную — по схеме страны: `80123450678` и `+70123450678` — 3-3-2-2, девять цифр после кода СНГ — 2-3-2-2 (Грузия и Киргизия — 3-2-2-2), восемь — 2-2-2-2.

Номером считается:
- `+` и код: для `+7` ровно 10 цифр следом, для кодов СНГ (373, 374, 375, 380, 992–996, 998) — положенная длина, для остальных стран — 8–15 цифр не разрядами тысяч (`+5 000 000 000` остаётся числом);
- префикс `8`/`7` и 10 цифр: отдельной группой (`8 900…`, `8-800-…`), со скобками (`8(900)…`) или вплотную (`80123450678`, белорусское `80291234567`);
- 10 цифр со скобками (`(495) 123-45-67`), с нулём в начале (`044 123 45 67`) или группами 3-3-2-2 (`012 345 06 78`);
- код СНГ без плюса и хотя бы три группы (`375 29 123-45-67`);
- местный номер через дефисы: `123-45-67`, `12-34-56`, `1-23-45`. Через пробелы (`123 45 67`) — нет: это слишком похоже на несколько чисел подряд.

`доб. 123` → «добавочный сто двадцать три». Десять цифр вплотную без префикса (`0123450678`) номером не считаются — так же пишут ИНН; обход — словарь замен.

## Служебные символы и TalkBack

Знак, которого нет в алфавите модели, фильтр молча выкидывает. Поэтому «·» и «→» между словами (так их пишут подписи интерфейса: `замок · Системный`, `«21» → «двадцать один»`) заменяются паузой: точка-разделитель — как запятая, стрелка — как тире. Перед коротким словом точка остаётся за единицами: `4 кВт · ч` → «четыре киловатт-часа». `выкл.` → «выключено»; `вкл.` не трогается, в тексте это чаще «включительно».

Правило «Служебные символы словами» (раздел «Разное», по умолчанию выключено) называет такие знаки, как TalkBack: `→` — «стрелка вправо», `×` — «знак умножения», `@` — «собака», `▾`, `⋮`, `✓`. Своя таблица (около ста знаков, названия как у TalkBack) — поверх имён Unicode CLDR (`assets/symbols_ru.tsv`, 360 с лишним знаков: математика, стрелки, валюты, типографика); обычную пунктуацию — точку, запятую, кавычки, скобки, тире — не называет ни та, ни другая: это паузы. Знаки, которые разбирают другие правила (`10 %`, `$5`, `№ 3`), читают они; «+» ударения не трогается.

Знак, который фильтр выкидывает, оставляет между словами пробел: `и/или` → «и или» (раньше «иили»).

Эмодзи (правило «Эмодзи и смайлы словами», включено) читаются по именам Unicode CLDR — тем же, что у Android: `Привет 😀` → «Привет, широко улыбается», `🐱` → «морда кошки». Имя отделяется от соседних слов запятыми, повтор подряд (`😂😂😂`) читается один раз, тон кожи не читается. Таблица — `assets/emoji_ru.tsv`, собирает `tools/emoji_ru.py`.

TalkBack в режиме пунктуации «Все»/«Большинство» шлёт названия знаков не текстом, а пометками TtsSpan на самих знаках — движок подставляет их текст (`TYPE_TEXT`, `TYPE_CARDINAL`).

## Форумы и веб-страницы

Проверено на теме RuVoice на 4PDA целиком — как её проходит TalkBack: меню, ники, заголовки сообщений, профили, подписи, вложения (около 800 разных фраз, `ForumTextTest`).

- Дата с годом из двух цифр: `20.09.26` → «двадцатого сентября двадцать шестого года». День и месяц — строго двумя цифрами, иначе это номер версии (`0.14.10`, `1.10.26`). Сокращённый месяц: `22 сент. 2026 г.` → «двадцать второго сентября…».
- Время без предлога — два числа, но ноль минут слышен: `18:06` → «восемнадцать ноль шесть», `16:00` → «шестнадцать ноль ноль». С предлогом — как было: `в 18:06` → «в восемнадцать часов шесть минут».
- Латиница у цифр: `13pro` → «тринадцать про», `77ruS` → «семьдесят семь ру эс» (раньше число склеивалось с латиницей, и омоглифы делали из `4PDA` «четырерда»). Названия с устоявшимся чтением — отдельным списком (`namedReadings`): `4PDA` → «четыре пи ди эй», и в адресе `4pda.to`. Одиночная буква перед цифрами — названием: `S20` → «эс двадцать», `v2`, `i7`, `X3`; `N2` — знак номера, не трогается.
- Слово со склеенными заглавными — по частям: `EdgeTTS` → «эдж ти ти эс», `MoonReader`, `FoxyBook`; слова из словаря (`iPhone`, `YouTube`) и приставка из одной строчной (`dB`, `eBook`) — целиком. Одиночная заглавная латинская — названием: `V` → «ви».
- Латиница вплотную к русскому слову — два слова: `файлMicrosoft` → «файл майкрософт»; одна латинская буква внутри русского слова — по-прежнему опечатка раскладки.
- Имя файла: `pack.zip` → «пак точка зип», `1.mp4` → «один точка эм пэ четыре».
- Черта из знаков (`-----`, `=====`, `***`) — пауза между словами, у края фразы и после точки — ничего. Стрелки из знаков (`->`, `>>`, `=>`) — как `→`. `+` не перед гласной — «плюс» (`Moon+ Reader`, `C++`). Пустые паузы подряд (`[][][]`, `))`) — одна.
- Смайлы (правило «Эмодзи и смайлы словами») — глаголом, как эмодзи: `:)` `^_^` — «улыбается», `:D` `xD` — «смеётся», `;)` — «подмигивает», `:(` — «грустит», `T_T` `:'(` — «плачет», `o_O` — «удивляется», `<3` — «сердце». Коды смайлов форумов (картинка на 4PDA приходит от TalkBack подписью): `:blush:` — «краснеет», `:censored:` — «цензура», незнакомый — самим словом.
- Скобки без пары, как пишут в рунете: `спасибо))`, `ладно)))))` — «улыбается», `жаль((` — «грустит», один раз на серию. Парные скобки и одна `)` без пары — пауза, как раньше: текст приходит по предложениям, и скобка из книги часто закрывается уже в следующем.
- Разряды через обычный пробел склеиваются и тогда, когда группа начинается с нуля: `14 033` → «четырнадцать тысяч тридцать три» (`1 200 читателей` — по-прежнему два числа). `20к`, `4.5к` — тысячи.
- Ударение готовой буквой со знаком — `Глáза`, `Слóва`, `Рукѝ` (латинские á, ó, é, ý рядом с кириллицей, кириллические ѐ, ѝ, гравис) — как «+»: раньше такая буква выпадала целиком.

## Что не чинится

- Английские маркеры эры `A.D.`, `CE`, `BCE` не распознаются, число перед ними читается количественным.
- Несуществующие суффиксы (`1-ее`, `6ее июля`, `3ее число`) читаются буквально. Нормализатор исправляет текст, а не опечатки.
- `2 местный` без дефиса — «два местный». С дефисом (`2-местный`) — «двухместный».
- Латиница транслитерируется правилами, не словарём: `iphone` → «айфон», `sherlock` → «шерлок», но редкие имена и бренды могут прозвучать неточно. Обход — словарь замен.

## Как это проверяется

Тесты нормализатора лежат в `app/src/test/java/ru/kost/ruvoice/text/`. Помимо своих кейсов, нормализатор сверяется с корпусом [ru-normalizr](https://github.com/NickZaitsev/ru-normalizr) (MIT) — 563 пары «вход → выход», снятые с его тестов и сложенные в `app/src/test/resources/ru_normalizr.json`. Тест `RuNormalizrCorpusTest` — трещотка: число совпадений не должно падать ниже зафиксированного, полный список расхождений после прогона лежит в `app/build/ru_normalizr_diff.txt`. Там, где расхождение сознательное (время, диапазоны лет, порядок слов при римских номерах глав, аббревиатуры по буквам), у кейса стоит поле `ours` с нашим вариантом; их выход в `out` сохранён. Корпус гоняется дважды — без таблицы морфологии и с ней; сейчас совпадает 492 из 495 кейсов основного режима с таблицей (485 без неё), три оставшихся — «10-20» как диапазон, «XIX в» без точки и падеж через союз.

Списки исключений для рода существительных на «-ь» выжаты из словаря [OpenCorpora](http://opencorpora.org/) (CC BY-SA 4.0) через `pymorphy3-dicts-ru`.
