# Доступность: TalkBack

RuVoice — движок, через который говорит TalkBack, и приложение, которым незрячему надо уметь
пользоваться. Ниже — что TalkBack шлёт движку, что из этого мы учитываем, и план правок интерфейса.
Источники: исходники TalkBack (github.com/google/talkback), справка developer.android.com по
TextToSpeechService, TtsSpan и доступности View.

## Что TalkBack шлёт движку

- **Текст с TtsSpan.** В режиме пунктуации «Все»/«Большинство» TalkBack не вписывает названия знаков
  в текст, а вешает на каждый знак `TtsSpan.TYPE_TEXT` с `ARG_TEXT` = «запятая»
  (`SpeechControllerImpl.makeSpeakablePunctuation`). Так же — свёрнутые повторы («15 дефисов»).
  В режиме «Некоторые» (по умолчанию) пунктуацию читает движок.
- **Одна буква** — буква под курсором, эхо ввода, клавиша; заглавная — «прописная буква Б.».
  Читаем имя буквы (правило `letter_name`).
- **Эхо ввода и удаления** — буква или знак в шаблоне: «Текст %1$s удален.», «Вырезан текст "%1$s"»,
  «Вставлен текст "%1$s"», «Выделен текст "%1$s"», «Отменено выделение текста "%1$s"», «Буква "d" удалена»
  (TalkBack, `utils` и `talkback` values-ru). Jieshuo (github.com/nirenr/jieshuo, в репозитории только
  ресурсы): «%s Заглавная буква %s», «Заглавная %s», «%s Заглавная»; «Удаление заглавная Р» на телефоне
  слышно, но слова «Удаление» в его ресурсах нет — видимо, подпись клавиши клавиатуры или код чтеца.
- **Прерывание.** Каждый новый фокус — `QUEUE_DESTROY`: сбрасывается очередь *всех* приложений,
  включая наше «Прослушать». `onStop` приходит почти на каждый свайп.
- **Темп** — множитель TalkBack 0,1–6,0, умноженный на системный темп; высота 0,2–2,0.
- Звуки-иконки (earcons) TalkBack играет сам, фокус аудио тоже берёт сам.

## План

Отмечено [x] — сделано (интерфейс собран без проверки на устройстве — сборка шла без Android SDK).

### Движок
- [x] **TtsSpan.** `TYPE_TEXT`/`ARG_TEXT` и `TYPE_CARDINAL` подставляются текстом до разбора — пунктуация
  «Все» у TalkBack больше не молчит.
- [x] **Остальные типы TtsSpan** (`SpanSay`): телефон (`PhoneNumberUtils.createTtsSpan` — звонилка, контакты)
  группами с ведущими нулями и «добавочный», время «семь часов пять минут», дата «вторник, пятое марта…»,
  деньги «сто рублей пятьдесят копеек», величины, порядковые с родом и падежом, дроби, адреса, «по цифрам»
  (`TYPE_DIGITS`) и «как написано» (`TYPE_VERBATIM` — буквы по имени). Приложение разметило — угадывать
  по виду не нужно.
- [x] **Коды и номера карт** — правило в «Числах», включено: «Ваш код: 482913» — «четыре восемь два, девять
  один три», если рядом «код», «пароль», «PIN», «CVC»; карта «1234 5678 9012 3456» и «•• 1234» — по цифрам
  группами. «Код 2024 года», «кодекс 1234», «код региона 77» не трогаются.
- [x] **Английский другим движком** (`en_proxy_sr` — для чтеца, `en_proxy_books` — для книг, оба выключены):
  английские слова и фразы читает движок, выбранный на телефоне (Google, Samsung, RHVoice…), русское —
  Silero. Порог «от скольких слов подряд» у чтеца свой, по умолчанию 1 — пункты «Settings», «Wi-Fi»,
  «GAME OVER» английским голосом; сокращения капсом («USB», «OK»), римские числа, ссылки — по-русски.
  Движку чтеца даётся 2 с на подключение и 2,5 с + 20 мс на знак на звук: не успел — фраза по-русски,
  чтец не молчит. Громкость английского подтягивается к Silero, темп и громкость поправляются ползунками.
- [x] **LocaleSpan.** TalkBack режет текст по LocaleSpan и перед куском зовёт `setLanguage(en)`. Раньше
  движок отвечал «не поддерживается» и кусок читался транслитерацией. Теперь, если английский включён
  и движок выбран, отвечаем «да» (и отдаём голос `english-en`): латиница такого запроса уходит другому
  движку с первого слова, кириллица — всё равно Silero, так что телефон с английским интерфейсом русские
  книги по-английски читать не начнёт.
- [x] **Эхо ввода и удаления.** Фраза из одной буквы или знака и служебных слов (шаблоны выше) —
  с именем: «Удаление заглавная Р» — «удаление, ээр, заглавная», «Текст прописная буква Р. удален.» —
  «текст, ээр, прописная буква, удален», «Удаление ,» — «удаление, запятая» (раньше «ррр» и потерянный
  знак). Только если во фразе нет других слов; у чтеца всегда, у книг — тумблером `letter_echo_all`
  в «Разном». В и Ы — как у голой буквы («вэ.», «— ы»).
- [x] **Служебные символы.** «·» и «→» между словами — паузы (как запятая и тире), «выкл.» — «выключено».
- [x] **«Служебные символы словами»** — правило, первое в «Разном», по умолчанию выключено: знаки, которые
  модель не произносит, читаются по имени, как у TalkBack («стрелка вправо», «знак умножения», «собака»).
- [x] **Эмодзи словами** — правило в «Разном», включено: имена Unicode CLDR («😀» — «широко улыбается»),
  тон кожи не читается, повтор подряд — один раз.
- [x] **Выкинутый знак не склеивает слова**: «и/или» было «иили», стало «и или».
- [x] **Имена символов из Unicode CLDR** (`symbols_ru.tsv`, 360+ знаков) под своей таблицей в стиле TalkBack;
  пунктуация не называется.
- [x] **Одиночный знак** («#» с клавиатуры, знак под курсором) — по имени, а не тишина (правило `letter_name`).

### Профиль «Чтение с экрана (TalkBack)» (раньше «Чтение с экрана»)
- [x] **Кто прислал текст.** Система кладёт в запрос uid приложения, вызвавшего `speak`
  (`TextToSpeechService`: `Binder.getCallingUid()` → `SynthesisRequest.getCallerUid()`); TalkBack говорит
  из своего процесса (`FailoverTextToSpeech`). Экранный чтец — пакет из списка известных
  (`com.google.android.marvin.talkback`, `com.android.talkback` — открытая сборка, Samsung, Huawei, Jieshuo,
  Dianming) или любой пакет с включённой службой доступности с речевым откликом (`FEEDBACK_SPOKEN`).
  Службы видны движку через `<queries>` в манифесте. «Выбор для озвучивания» живёт в том же пакете,
  что TalkBack, — тоже считается чтецом.
- [x] **Секция «Чтение с экрана»** в правилах (первая): служебные символы словами, без голоса прямой речи,
  без тишины перед фразой, без пауз между предложениями — только для запросов чтеца, всё включено.
- [x] **«Кто читает через движок»** — последние 8 отправителей с решением автоматики и тумблером
  «экранный чтец» (ручной выбор запоминается). Отправитель пишется и в журнал запросов
  («Устранение неполадок»). Проверить на телефоне: TalkBack, Samsung, другие чтецы.
- [x] **Не выгружать модель, пока работает экранный чтец** (`sr_keep_loaded`, включено) — важнее «Выгружать
  модели при простое»; тот же переключатель на вкладке «Паузы» рядом с минутами (одно правило).
- [x] **Темп и высота для TalkBack** — два ползунка в секции, вместо ползунков «Голоса»; потолок темпа для
  чтеца ×6 (TalkBack шлёт до ×6), книгам ×3, ползунки не менялись.
- [x] **Кэш коротких фраз** (до 80 символов, 12 МБ, вытесняется дольше всех не звучавшее): звук и точки
  подсветки; ключ — текст, голос, частота, темп, высота и отпечаток настроек и словарей, любая правка
  его меняет. В журнал: «из кэша».
- Direct Boot не делаем: до первой разблокировки TalkBack читает встроенным движком телефона.

### Интерфейс
- [x] **«Прослушать» → «Стоп».** Пока звучит, кнопка не выключается, а становится «Стоп»; сброс TalkBack
  (onStop) возвращает её в прежний вид.
- [x] **Строка правила — один переключатель** («Телефоны, включено, …»), тумблер фокус не берёт.
- [x] **Заголовки секций** — `accessibilityHeading` в стиле `Section` (и у секций правил).
- [x] **Ползунки темпа и высоты** — с названием («Темп», «Темп прямой речи»), значение «1,25»;
  строка подписи над ними для TalkBack скрыта.
- [x] **Списки ударений, замен, «Проверки»** — двойной тап подписан («Изменить», «В словарь»),
  в меню действий «Удалить» / «Скрыть» / «Вернуть из скрытых»; ▶ — «Прослушать: слово».
- [x] **Состояния словами** — сортировка «По алфавиту» (включено/выключено), «Ударение» и «Проверить»
  в диалоге замены (развёрнуто/свёрнуто, без треугольника в названии), «Где искать: все списки».
- [x] **Значки-кнопки** — «+» называет, что добавит («Добавить слово» / «Добавить замену»), «Удалить»
  у паков — с именем пака.
- [x] **Справки** — «меню ⋮ справа вверху»; в «Как включить» — абзац про TalkBack.
- [x] «3 раз» → «3 раза» (plurals).

- [x] **Поиск по правилам** — по названиям и подписям, «Найдено 3 пункта» TalkBack читает сам (live region).
- [x] **Чипы ударения**: одинаковые гласные («молоко») различимы — ударная буква заглавной, жирной и цветом
  («молокО́»), для TalkBack — «молоко́ — 3-й слог из 3, «о»» (номер слога звучит любым голосом). Над
  чипами — «Ударная гласная».
- [x] **Подсветка слов** после подстановки TtsSpan указывает в текст клиента (карта смещений).
- [x] Ссылки «Как это работает» / «Как включить» — область нажатия 48 dp.
- [x] **Espresso + Accessibility Test Framework** (`AccessibilityChecksTest`): вкладки настроек, правила с
  поиском, «Решение проблем», «О программе» — проверки на каждом действии по всему окну.
- [x] **Шрифт 200 % и тёмная тема** (`LargeTextTest`): те же проверки плюс своя — надпись не обрезана по
  высоте. Настройки ставятся через shell и возвращаются после прогона.

- [x] **«Разбор»** — пометки словами («Прямая речь, конец абзаца.», «Модели: …», «Пауза 300 мс.»),
  а не «[¶]» и «→», которые TalkBack не произносит.
- [x] **Громкость голоса** — ползунок на «Голосе» и свой в «Чтение с экрана» (×0,5–2), громче — с мягким
  ограничением пиков (как у RHVoice, там 25–400 %).

- [x] **Сообщения** (WCAG 2.2.1): Snackbar с «Отменить» при экранном чтеце держится 30 с (до кнопки ещё
  дойти жестами), результат «Проверить на тексте» в диалоге замены TalkBack читает сам («Результат: …»,
  без «стрелки вправо»), последний Toast стал Snackbar.
- [x] **«Отменить»** (WCAG 3.3.4) — кроме удаления строки словаря: «В словарь» из «Проверки» (строка
  уходит из словаря, слово возвращается в список), очистка списка «Проверки», импорт настроек (прежние
  настройки из снимка, словари, которые принёс импорт, удаляются). Удаление пака и словаря — через
  подтверждение, как было.
- [x] **Заголовки у всех диалогов** (WCAG 2.4.6): без заголовка TalkBack называет окно «Оповещение».
  «Добавить слово» / «Изменить слово», «Добавить замену» / «Изменить замену», «Проверить», «Удалить пак?»,
  «Удалить список?», «Импорт настроек», «Установка пака…», «Очистить список «…»?». Окна — по `android:label`,
  вкладки TalkBack объявляет сам.
- [x] **Клавиатура и Switch Access** (WCAG 2.1.1, 2.4.7): строки словарей и «Проверки», ссылки справки
  берут фокус (раньше до них доходил только TalkBack) и подсвечиваются при фокусе; Enter в поле слова,
  замены и имени списка — «Сохранить»; Ctrl+F — в поиск (правила, списки). Espresso: всё, что нажимается,
  берёт фокус.
- [x] **Выпадающие списки с клавиатуры** (голос, частота, голос прямой речи, выбор словаря, словарь в
  «Проверке»): Enter, пробел или Alt+↓ открывают — раньше только касание и TalkBack. `KeyboardTest`: в
  «Чтении с экрана» Enter переключает строку, стрелки двигают темп, высоту и громкость; Enter открывает
  список голосов.
- [x] **Раздел переименован** в «Чтение с экрана (TalkBack)» — как категория «Программы чтения с экрана» в
  Android; под заголовком — какие программы это (TalkBack, Samsung, Huawei, Jieshuo, Dianming).
- [x] **Прогресс словами** (WCAG 4.1.3): «Имена из книги» и «Ударения в книгу» — проценты в живой области,
  чтец говорит их сам, фокус остаётся на «Отмене»; при чтеце — шагами по 10 %, иначе голос перебивал бы
  себя каждые полсекунды.
- [x] **«Сохранить» в окне слова из «Проверки»** неактивна, пока нечего сохранять (пустая замена): раньше
  окно молча закрывалось без записи.
- [x] **Заголовки на Android 6–8**: атрибут `accessibilityHeading` в стиле `Section` работает только с 9;
  раньше заголовки разделов из разметки отмечает код (`markHeadings`, по метке стиля).
- [x] **«Установка пака…»** — с пояснением: голоса копируются, до минуты, окно закроется само.
- [x] **«Английский другим движком».** Тумблеры — как остальные правила (одна строка — один переключатель).
  При включении — диалог: какой движок и что текст английских фраз уходит ему; «Отмена» или «назад»
  тумблер возвращают. Согласие — на этот движок: удалили его — английский читается по-русски, строка
  «Движок» так и говорит, другой движок сам не подставляется. «Движок» и «Голос» для TalkBack — кнопки
  «Выбрать движок/голос»; значение — живая область: «Спрашиваю голоса у движка…» и новый выбор чтец
  говорит сам, фокус остаётся на строке. Голоса словами: «Английский (США), голос iol, нужен интернет»,
  а не «en-us-x-iol-local · …». Голос по умолчанию — офлайн, если он есть; нет — строка «Голос»
  предупреждает, что текст может уходить в интернет. Нет других движков — окно с объяснением, а не
  тишина. Порог слов — поле с подписью под каждым тумблером; темп и громкость английского — ползунки
  с названием и значением (`rateSlider`).

### Отложено

## Сравнение с RHVoice

RHVoice — второй распространённый русский движок у незрячих (github.com/RHVoice/RHVoice, Android 1.18.4).
По исходникам, не по устройству.

**Есть у RHVoice, нет у нас:**
- **Direct Boot** — говорит до первой разблокировки после перезагрузки (экран ввода PIN). Наш сервис не
  `directBootAware`: там читает встроенный движок телефона. Решено не делать.
- ~~Эмодзи по имени~~ — сделано (правило «Эмодзи и смайлы словами»).
- ~~Английские слова английским голосом~~ — сделано иначе: у RHVoice свой английский голос в профиле
  («Александр+Alan»), у нас английское читает другой движок телефона по выбору (правило «Английский другим
  движком»); без него — транслитерация (`hello world` → «хеллоу ворлд»).
- ~~Громкость голоса~~ — сделано.
- **Скачивание голосов из приложения** — у нас пак ставится файлом.
- Одиночный неизвестный знак — «символ <код>» (у нас теперь по имени из таблицы, неизвестный — тишина).

**Есть у нас, нет у RHVoice:** TtsSpan (RHVoice берёт `getText()` — пунктуация TalkBack «Все» у него тоже
молчит), SSML на Android (у RHVoice только в SAPI/NVDA), падежи числительных, порядковые, даты, единицы,
телефоны, омографы, пользовательские замены с regex, быстрый старт. Подсветка слов есть у обоих.
Темп у RHVoice на Android тоже упирается в ×3.
