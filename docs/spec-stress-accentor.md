# Спека 2. Промахи акцентора вне омографов → системный словарь

## Зачем

На HomographResolutionEval (1741 предложение) 148 из 309 промахов — не омографы, а слова, в которых
ошибается нейросетевой акцентор Silero Stress: имена, редкие и длинные слова. Такие слова правит системный
словарь ударений (`app/src/main/assets/dicts/stress/Системный.txt`, собирается `tools/system_dicts.py` из
`tools/stress_fixes.txt`). Сейчас в нём 1307 слов — только те, где оба арбитра (AOT и Викисловарь) вместе
против модели. Нужно добрать остальное, не копируя чужие словари оптом.

## Источники

- `/home/kost/serverApp/ruvoice/homographs-unknown.txt` — 9519 слов не из homodict, где модель разошлась со
  словарём Демагога (формат в шапке файла: слово | варианты словаря с частотой | v5 | silero-stress; ниже
  фразы). Это главный список кандидатов.
- `app/build/homo_eval_miss.txt` — промахи `tools/homo_eval.py` (запуск: `<scratchpad>/sstress/bin/python
  tools/homo_eval.py`), среди них не-омографы.
- `app/build/aot_forms.tsv`, `app/build/wikt_forms.tsv` — арбитры (сделать заново `tools/aot_forms.py`,
  `tools/wikt_forms.py`, если файлов нет; входы в scratchpad `aot/`, `kaikki_ru.jsonl`).
- `<scratchpad>/ru_full.txt` — частотность (FrequencyWords, OpenSubtitles).
- `app/src/test/resources/local/demagog.txt` — словарь Демагога (симлинк, гитигнор). В код и доки — только как
  «словарь Демагога».

## Что сделать

1. `tools/stress_fixes.py`: новый режим `build3` (или расширить `build`): для каждого слова из
   `homographs-unknown.txt` и не-омографных промахов eval собрать голоса: словарь Демагога (вариант с
   максимальной частотой), AOT, Викисловарь, модель. Правило отбора в `stress_fixes.txt`:
   - словарь + хотя бы один арбитр согласны между собой и против модели → кандидат;
   - у арбитра слово однозначно (одно ударение в `aot_forms.tsv`/`wikt_forms.tsv`), иначе это скрытый
     омограф — в отдельный файл `app/build/hidden_homographs.txt` (для спеки 3, не в словарь);
   - те же фильтры, что сейчас: не имя/фамилия/отчество по тегам, не слово с «ё» (и не то, что модель
     читает через «ё»), не в `SKIP`, не в exceptions модели, не уже в списке;
   - комментарий строки: частота, кто голосовал («словарь+AOT», «словарь+wikt»).
   Ожидание: плюс 1–2 тыс. слов. Полный список вывести в `app/build/stress_fixes_new.txt` для просмотра,
   в `tools/stress_fixes.txt` дописывать только после просмотра (см. п. 3).
2. Слова, которых нет ни в одном арбитре (имена, редкости): отсортировать по частоте, верхние 300–500 —
   в `app/build/stress_names_review.txt` с контекстом-фразой из `homographs-unknown.txt`. Это на ручной
   просмотр пользователя, в словарь не класть автоматически.
3. Просмотр кандидатов п. 1: пройти список глазами порциями по ~200 (сортировка по частоте), выкинуть
   явные имена, жаргон, опечатки словаря; сомнительное — в `SKIP` с комментарием. Слова с частотой < 3 в
   FrequencyWords и без контекста — не брать.
4. `python3 tools/system_dicts.py` → обновлённый `Системный.txt`. Проверить, что `tools/stress_fixes.txt`
   и системный словарь не содержат имени файла словаря Демагога и его строк «как есть» (формат у нас свой:
   «слово = сл+ово  # комментарий»).
